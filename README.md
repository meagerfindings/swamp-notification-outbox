# swamp-notification-outbox

[swamp](https://swamp.club) extension `@mgreten/notification-outbox` — a
transport-neutral, secret-redacting notification outbox that enqueues
deduplicated records and drains them through a caller-supplied transport.

📖 **Extension documentation:** [extensions/models/README.md](extensions/models/README.md)

📦 **Install:** `swamp extension pull @mgreten/notification-outbox`

## Repository layout

This repository is a swamp workspace (its own `.swamp.yaml` repo). The
publishable extension lives under [extensions/models/](extensions/models/).
